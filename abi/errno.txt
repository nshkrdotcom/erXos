# The errno table (docs/design-programs.md, "The POSIX-lite personality"):
# every name erXos's musl defines in <errno.h>, with FreeBSD 15.1's number
# (sys/sys/errno.h). The generator writes musl's bits/errno.h from it, so
# musl's errno values, and the strerror table indexed by them, are FreeBSD's.
# The table holds every name that header defines but ELAST, which names
# the largest errno number rather than an error;
# test/host/abi_errno_test.rb compares it with the header at deps.lock's
# freebsd-errno pin.
#
#   errno NAME NUMBER [alias NAME]
#
# NAME is the protocol's name of the error, the C name in lower case. An
# alias is a second C name of the same number, which the table lists so that
# it is a name no other row takes; it is never a protocol name, so one error
# has one name in a reply. A name the table does not list is not an errno.
