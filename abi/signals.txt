# The signal table (docs/design-programs.md, "Signal numbers"). Numbers are
# FreeBSD 15.1's (sys/sys/signal.h), default actions FreeBSD's
# (sys/kern/kern_sig.c, sigproptbl) and descriptions FreeBSD's sys_siglist
# text (lib/libc/gen/siglist.c); test/host/abi_signals_test.rb compares the
# numbers, names and descriptions with those files at deps.lock's
# freebsd-signal and freebsd-siglist pins.
#
#   signal NAME NUMBER ACTION [alias NAME] "DESCRIPTION"
#   signal NAME NUMBER reserved [alias NAME]
#   reserved_signal NUMBER
#   realtime FIRST LAST ACTION
#   signal_set SET NAME...
#
# NAME is the signal's name without SIG, in lower case. ACTION is
# terminate, ignore, stop or continue for a signal a program may name,
# which strsignal describes with DESCRIPTION, and reserved for a number the
# C library keeps for itself, which no program may name and strsignal does
# not describe. reserved_signal is such a number that has no name.
# realtime numbers the real-time signals FIRST to LAST and names them as
# sig2str does: rtmin, rtmin+1 up to the middle of the range, then rtmax-N
# down to rtmax; strsignal describes none of them. A number the table does
# not list is not a signal. signal_set names a set of signals a program may
# name, each by its NAME, for a protocol that carries only those; the ABI
# header gives it as ?ERX_<SET>_SIGNAL_MEMBERS.
