# The network domain's interfaces (docs/design-network-stack.md, "The grant"): net,
# a client's sockets, and netadmin, interface configuration and every client's
# statistics. Their operations are the socket protocol's own messages, which no
# facet row names, so neither declares any. The manifest grants neither to the
# system domain (property 15), and every grantee of net carries frames of at least
# net_max_frame_min bytes, the protocol's max_frame floor: a piece of 64 KiB and its
# envelope (docs/design-domains.md, "Floors from a protocol";
# docs/design-network-stack.md, "Message sizes").
# A facet row's parameters of net are the grant's limits of the same names, which the
# mint hands the grant: sockets, the sockets it may hold open at once, and buffers, the
# bytes of send and receive buffer it may reserve across them. A limit a row leaves out
# takes the grant's default (erx_net_grant_core). The bounds cap one grant, not their sum:
# at most 4,096 sockets, the design's TIME-WAIT limit and a small part
# of the ephemeral ports and ICMP echo identifiers, and from 128 KiB, room for one
# connection's initial buffers (erx_net_grant's tcp_sendspace and tcp_recvspace), to
# 64 MiB of buffers; nothing sums the grants' buffers against the network domain's memory
# (TODO.md).
# ports and listen are sets of at most 16 ports, each stated by a parameter line of its
# own: ports, the only local ports the grant may bind explicitly, in place of the default
# 1024 to 65535, and listen, those of its ports a listener may bind, every one of
# them when the row states none. The network domain's mint takes each port P as the range
# {P, P} the grant holds (erx_net_admit:mint/2). A port below 1024 is privileged, as
# FreeBSD reserves it (ipport_reservedhigh, in_pcb.c:132), so the grant may bind it only
# when the row lists it.
# net_grant is the manifest check's acceptance of the parameters (property 15): their
# declarations bound them, every listen port is one of the grant's ports, and a port below
# 1024 is listed by one grant alone, to a configured domain, so no other grant can bind it
# first; the grant enforces them at run time.
# A facet row of net the build derives takes the quantities below; netadmin declares
# none, so no derived row grants it.
service net 3
  served_as message
  parameter sockets 1 u64 optional range 1 4096 checked_by net_grant
  parameter buffers 2 u64 optional range 131072 67108864 checked_by net_grant
  parameter ports 3 u64 set 16 range 1 65535 checked_by net_grant
  parameter listen 4 u64 set 16 range 1 65535 checked_by net_grant
  quantity max_request 64
  quantity in_flight 16
  quantity reductions 100000
  quantity period_ns 1000000000
  quantity max_heap_size 65536
service netadmin 4
  served_as message
limit net_max_frame_min u32 131072
# The least port FreeBSD does not reserve to privilege (ipport_reservedhigh + 1,
# in_pcb.c:132), the low end of the grant's default ports (erx_net_grant_core).
limit net_unprivileged_port u32 1024
