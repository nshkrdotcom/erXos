# The display's widget trees (docs/design-abi.md, "Widget format", and
# docs/design-display.md, "Widget trees"): value types, image types,
# properties, kinds and the records of the binary form. Value types and
# image types share one namespace, properties one and kinds one; image types, properties and kinds each
# number from 1 to 255. A kind takes the properties marked common and those
# listed beneath it. tools/gen_abi.rb generates erx_ui_schema, the validator
# of whole trees, from it.

# The most children one node of a tree has: it bounds the difference of two
# trees and keeps every insert's and move's index within a u16.
limit ui_children u32 1024
# The most rectangles one damage report carries.
limit ui_damage_rects u32 16
# The most encoded bytes an image node's picture holds, which the PNG
# reader erx_png also refuses beyond.
limit ui_picture_bytes u32 49152

# Placement of a node within the room it gets.
enum ui_align u8
  value start 0
  value center 1
  value end 2
  value fill 3

# How a node's text ranks in its window (docs/design-desktop-programs.md,
# "Widget format additions"); a renderer picks the face and size.
enum ui_role u8
  value display 0
  value title 1
  value heading 2
  value body 3
  value numeric 4
  value caption 5

# Which way the value a label shows has moved (docs/design-desktop-programs.md,
# "Widget format additions"); a renderer shows up and down in the palette's
# ok and critical colours and flat in the label's own.
enum ui_trend u8
  value up 0
  value down 1
  value flat 2

# What a container is: a renderer marks a section, a toolbar or a sidebar.
enum ui_area u8
  value section 0
  value toolbar 1
  value sidebar 2

# The icon set (docs/design-desktop-programs.md, "Icons"): the item a node
