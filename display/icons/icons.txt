# The desktop's icon set (docs/design-desktop-programs.md, "Icons"), drawn
# for erXos. Each icon is a set of paths on a GRID-unit square, y downward,
# stroked STROKE units wide with round joins and caps. An icon has a base
# layer, drawn in the theme's `secondary` colour, and may have an accent
# layer, drawn in `accent`; each `base` or `accent` row adds subpaths to its
# layer. A path is SVG path data in absolute commands: M x y, L x y,
# C x1 y1 x2 y2 x y, and Z, which closes the subpath. The icons are exactly
# those of abi/formats/ui.txt's `ui_icon` enumeration, in any order.
#
# Lines lie on the lattice 0.75 + 1.5k where they can, so a horizontal or
# vertical stroke covers whole pixels at 16 pixels (one pixel wide) and at
# 32 (two pixels wide).
