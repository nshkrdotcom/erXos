# User guide

How-tos for people who run erXos. What each part is and why it is built
that way is in the design documents, starting at [design.md](../design.md);
building the system and running QEMU is in the [top-level README](../../README.md).

* [Raspberry Pi 4](raspberry-pi-4.md): write the card, boot the board,
  check its SD card and Ethernet, and netboot builds from a Mac.
